# Before Dec 4: what to bring

Please do this before the day so we can start building right away. It takes about 10 minutes.

**1. A Google account** for Colab. A Northeastern Google account works. That's the only
account you need. (A Hugging Face account, huggingface.co, is a nice extra for the Demo team.)

**2. A laptop** with Chrome or Firefox and its charger. Nothing to install: everything runs
in Google Colab in the browser. Any laptop works, including a Chromebook.

**3. The setup check (by Dec 2)**
1. Open your team's notebook link (we'll send it).
2. Click **File → Save a copy in Drive**.
3. Run the first cell (▶). After about a minute it prints **✅ Ready**.
4. Send us a screenshot of that line. If you see an error instead, send that. We'll fix it before the day.

**Good to know (optional)**

- Skim the first page of Meta's paper: *A generic non-invasive neuromotor interface for
